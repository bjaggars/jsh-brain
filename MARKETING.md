# MARKETING — the JSH Marketing Engine

Doctrine for launching every JSH product. Full playbook: Claude Project doc `claude/jsh-marketing-engine-playbook-v1.md`.
Production rig: `reference/studio/`.

## The idea
Build a studio, not a pile of videos. Each product already has a **set** (a fictional demo tenant on TEST) and a
**script** (its E2E test cases). Code drives the app, captures real footage, composites it, voices it and renders every
format. UI changes are a re-render, not a reshoot.

## The Launch Kit (every product fills all nine)
1. Message house — tagline, promise, 3–4 pillars, proof
2. Persona set — pain, hook, hero moment, channels
3. Claims ledger — a feature is marketed only once it's live on prod
4. Film set — fictional demo tenant seed (TEST only)
5. Test-to-script map — each key test case → a scene
6. Asset matrix — store previews, hero, persona films, ad cuts, academy, founder, proof, what's new
7. Channel plan — stores, paid, organic, SEO, partners
8. Calendar — T-minus to launch
9. Scorecard — store conversion, CPI, activation, homeowner→add-agent, trial→paid, hook rate

## Standing rules
- Real app footage; fictional people. No invented testimonials (FTC). AI people labeled as AI.
- App Store previews: real captures only, 15–30 s, ≤30 fps, exact accepted resolution.
- Founder rules at six gates: positioning, scripts, casting, rough cut, final + claims check, spend.
- Stock and music must be licensed before anything is published.
