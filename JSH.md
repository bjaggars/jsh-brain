
## Delivery rule: scripts arrive in chat, always
Any DB change script or seed addendum Brice needs to run is ALWAYS pasted
in full in the chat — generated by cat-ing the committed file (byte-identical,
sha256 noted) — never delivered as "it's in the repo." Brice should never
have to dig. (Standing practice, Brice 8/5/26; mechanics per MBV LEARNINGS #14.)
